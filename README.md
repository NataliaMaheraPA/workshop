# Workshop: Claude Code — від інтуїції до системи

Матеріали воркшопу для PettersonApps: сетап репозиторію, робота над фічею,
Figma MCP для побудови UI.

```bash
open index.html
```

Дек самодостатній — без збірки й залежностей. Стрілки гортають слайди,
`O` показує сітку, `B` затемнює екран, `#/7` відкриває сьомий слайд.

- `docs/handout.md`, `docs/workshop-handout.pdf` — роздатка: посилання й команди
- `docs/speaker-notes.md` — текст виступу по слайдах
- `docs/BRIEF.md` — початковий бриф; дек із того часу розійшовся з ним
- `assets/` — діаграми (SVG) і скриншоти (WebP)
- `CLAUDE.md` — правила для агента
