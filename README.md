# Workshop: Claude Code — від інтуїції до системи

Матеріали воркшопу для PettersonApps. Три частини: сетап репозиторію,
робота над фічею, Figma MCP для побудови UI.

## Презентація

`index.html` — самодостатній дек, без збірки й залежностей:

```bash
open index.html
```

- `←` `→` або пробіл — слайди й фрагменти, `Home` / `End` — до країв
- `O` — сітка всіх слайдів, `B` — затемнити екран
- клік по зображенню — лайтбокс на весь екран
- `#/7` у адресі відкриває сьомий слайд

## Роздатка

`docs/handout.md` — посилання, команди й файли сетапу з виступу.
`docs/workshop-handout.pdf` — та сама роздатка на одну сторінку, з клікабельними
адресами; збирається з `docs/handout.html`:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
  --no-pdf-header-footer --print-to-pdf=docs/workshop-handout.pdf docs/handout.html
```

## Решта

- `docs/speaker-notes.md` — текст виступу по слайдах. У самому деку нотатки
  до кожного слайда лежать поруч з ним і відкриваються кнопкою «нотатки».
- `docs/BRIEF.md` — початковий бриф на збірку. Історичний документ: дек із того
  часу розійшовся з ним по структурі.
- `assets/` — діаграми (SVG, інлайном у розмітку) і скриншоти (WebP).
- `assets/_theme.txt` — CSS-змінні, які використовують діаграми.
- `CLAUDE.md` — правила для агента: класи, каскади, дерево файлів, нумерація.
