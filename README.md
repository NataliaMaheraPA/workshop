# Workshop: Claude Code — від інтуїції до системи

Матеріали воркшопу для PettersonApps.

- `docs/BRIEF.md` — бриф на збірку презентації. **Claude Code починає звідси.**
- `docs/speaker-notes.md` — повний текст виступу по слайдах.
- `assets/` — SVG-діаграми для слайдів (вставляти інлайном).
- `assets/_theme.txt` — CSS-змінні, які використовують діаграми.

## Як почати в Claude Code

```
Прочитай docs/BRIEF.md і docs/speaker-notes.md.
Спершу налаштуй проєкт: CLAUDE.md, .claude/settings.json, потрібні скіли.
Далі — план збірки index.html. Код не пиши, поки не погодимо план.
```
