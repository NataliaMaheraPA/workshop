description: Plan a task — interrogate me first, then propose
---

Explore the code first. Then ask me clarifying questions about everything
that admits more than one reasonable answer.

Ask in rounds, not one at a time. Attach a recommended answer to each question
so I can push back instead of starting from a blank page.

Only after I answer, write the plan. Do not touch the code.

For a deeper interrogation — a loose idea that needs sharpening before it can
become a plan at all — use `/grill-me` in a fresh session instead.
