# Slide markup rules

Applies only when editing `index.html`. The full style guide lives in `CLAUDE.md`.

- Never add inline `style=""` to a new element. Pick an existing class, or add
  a class next to its relatives first.
- Never invent a new font size. The type scale is fixed in `CLAUDE.md`.
- A `mini-head` that introduces a list or a table ends with a colon.
- Slide comments `<!-- N ——— title -->` are sequential with no gaps. After
  inserting or deleting a slide, renumber all of them from the start.
